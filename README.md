# Two-Stage Operational Amplifier with Miller Compensation

## Project Overview

Designed and analyzed a two-stage CMOS operational amplifier using Miller compensation to improve stability and frequency response.

Proper transistor sizing, biasing, and compensation capacitor selection were performed to achieve the targeted analog performance specifications.

## Performance Specifications

| Parameter | Achieved Value |
|---|---:|
| DC Gain | 60 dB |
| Phase Margin | 66° |
| Unity Gain Bandwidth | 39.8 MHz |
| Slew Rate | 33.3 V/µs |
| -3 dB Bandwidth | 39 kHz |
| Load Capacitance (CL) | 3 pF |

## Simulation Analysis

### DC Analysis
Verified biasing conditions and operating regions of the transistors.

### AC Analysis
Evaluated gain, bandwidth, phase response, phase margin, and unity-gain bandwidth.

### Transient Analysis
Examined the large-signal response and slew-rate performance.

## Miller Compensation

Miller compensation was used to improve the stability and frequency response of the two-stage operational amplifier.
